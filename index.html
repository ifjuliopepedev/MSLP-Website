Sobre o jogo

My Sleeper é um sandbox automotivo focado em montagem e customização. Você escolhe o carro e o mapa, constrói tudo peça por peça e usa o carro para ganhar dinheiro, fazer trabalhos, correr e explorar.

Criação de mods

Como funcionam os mods

Os mods de My Sleeper são feitos no Unity. Você baixa o projeto de mods no GitHub, abre no Unity, cria seu conteúdo e publica na Oficina da Steam para outros jogadores instalarem.

Carros

Modelos, peças e configurações de carros novos.

Mapas

Cenários novos, com a sua própria cultura, atividades e desafios.

Peças

Componentes de motor, mecânica e visual para os carros.

  1. Prepare o Unity

    Instale o Unity e abra o projeto de mods do GitHub.

  2. Crie o seu mod

    Monte o carro, mapa ou peça dentro do projeto.

  3. Publique na Oficina

    Envie o mod para a Oficina da Steam e compartilhe.

Preparar o Unity

  1. Instale o Unity Hub

    Baixe o Unity Hub no site oficial do Unity e entre com sua conta (a licença pessoal gratuita basta para começar).

  2. Instale a versão certa do Unity

    Use a mesma versão do projeto. Ela está no arquivo ProjectSettings/ProjectVersion.txt do repositório. No Unity Hub, vá em Installs, escolha essa versão e instale.

  3. Baixe o projeto de mods

    Clone o repositório com o Git ou baixe o ZIP e extraia em uma pasta sua.

    git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
    Baixar o projeto (.zip) Ver no GitHub

  4. Abra o projeto no Unity Hub

    Em Projects, clique em Add, escolha a pasta do projeto e abra. A primeira abertura demora, porque o Unity importa todos os arquivos.

Dica. Mantenha o projeto de mods separado dos seus mods. Crie cada mod em uma pasta própria para atualizar o projeto base sem perder o seu trabalho.

Criar um mod

Escolha o tipo de conteúdo que você quer criar. O fluxo base é o mesmo para os três.

Carro

Importe seu modelo 3D, configure as peças e as características do carro e teste no editor.

Mapa

Monte o cenário em uma cena do Unity, defina os pontos de interesse e as atividades do mapa.

Peça

Crie o modelo e defina o encaixe e o efeito da peça no carro.

  1. Duplique um exemplo

    Comece copiando um dos exemplos do projeto e renomeie. É mais seguro do que começar do zero.

  2. Troque o conteúdo

    Substitua modelos, texturas e dados pelos seus.

  3. Teste no editor

    Rode o teste dentro do Unity antes de publicar e corrija o que aparecer no Console.

  4. Exporte o mod

    Use o Mod Creator do projeto para gerar o pacote do seu mod.

Publicar na Oficina da Steam

A Oficina da Steam é onde os jogadores encontram, instalam e atualizam os mods. O jogador se inscreve no mod e a Steam baixa o arquivo.

  1. Gere o pacote do mod

    Exporte o mod pelo Mod Creator, como descrito em “Criar um mod”.

  2. Prepare as informações

    Título, descrição, imagem de capa e etiquetas. Uma boa imagem de capa ajuda o mod a ser encontrado.

  3. Envie para a Oficina

    Envie pelo Mod Creator e escolha a visibilidade: privado para testar, ou público para todos.

  4. Atualize quando precisar

    Envie uma nova versão no mesmo item. Quem já está inscrito recebe a atualização pela Steam.

Abrir a Oficina
Direitos autorais. Publique apenas conteúdo que você criou ou tem permissão para usar.

Dúvidas frequentes

Qual versão do Unity eu devo usar?

A versão indicada em ProjectSettings/ProjectVersion.txt no repositório do projeto. Versões diferentes podem causar erros na importação.

Preciso saber programar?

Para trocar modelos, texturas e dados, não. Para criar comportamentos novos, é preciso conhecer C# no Unity.

O Unity abriu com erros. O que faço?

Confira se instalou a versão certa e leia a primeira mensagem de erro no Console. Se não resolver, peça ajuda no Discord com o texto do erro.

Onde peço ajuda ou mostro meu mod?

No Discord do jogo, ou abrindo uma issue no repositório do GitHub.
